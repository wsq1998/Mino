## 关键设计决策（留档）

- **清空废纸篓是唯一不可逆操作**：路线图原方案「对 ~/.Trash 逐项 shell.trashItem」原理不成立（原地不动），改走 `osascript 'tell application "Finder" to empty the trash'` + 三重护栏（强制二次确认 / 仅限 ~/.Trash / 绝不 rm）；代价是新增「自动化-控制 Finder」权限（osascript 错误码 -1743 判定被拒）
- **统一权限说明弹层扩为三项**：屏幕录制 / 辅助功能 / 自动化-控制 Finder，一次讲清；`consent.permsIntroSeen` 只弹一次；「继续」才置位
- **屏幕录制授权后必须重启 Mio 才生效**（Electron `askForMediaAccess` 不支持 'screen'，只能靠真发一次捕获触发 TCC）
- **E4「截图存文件」本版砍掉**：写 ~/Desktop 会触发第 4 项 TCC（桌面文件夹），违背「一次讲清」；`capture.dest` 留在 schema 无 UI
- **剪贴板历史只存内存绝不落盘**，重启即清空；密码过滤默认关（PRD Q3/Q8 裁决）
- **不透明度单一口径 = 0.3–1 小数**，百分数只在界面层；main.js `sanitizeSettings` 在 merge 之后收口（patch 里也可能带脏值）
