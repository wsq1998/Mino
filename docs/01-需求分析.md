# Mio · macOS 桌面陪伴机器人 — 需求分析

> 对标产品：蔚来 NOMI（车载情感机器人）
> 平台：macOS 桌面端
> 版本：v1.0 MVP

---

## 1. 产品定位

NOMI 的本质不是"语音助手"，而是**一个住在车里的、有表情的伙伴**——它把冰冷的语音交互变成一个"活物"的反应。

Mio 把这个理念搬到 macOS 桌面：一个常驻屏幕角落的小机器人，有生命感（呼吸、眨眼、好奇地看你），能表达情绪，点击它可以快速调用日常小工具。它不抢占注意力，但你知道它一直在。

**一句话定位**：桌面上有生命的快捷入口。

## 2. 目标用户与场景

| 场景 | 痛点 | Mio 的价值 |
|------|------|-----------|
| 长时间伏案工作 | 枯燥、无陪伴感 | 生命感动画 + 定时休息提醒 |
| 高频小工具调用 | 看时间/日期/番茄钟要切窗口 | 点一下 Mio 即用即走 |
| 专注工作 | 容易坐过头 | 番茄钟 + 久坐提醒，温和打断 |

## 3. 功能需求（MVP）

### 3.1 生命感系统（核心，P0）
- **待机呼吸**：身体缓慢起伏缩放
- **随机眨眼**：2~6 秒随机间隔
- **视线跟随**：眼睛跟随鼠标位置转动（NOMI 标志性行为）
- **随机小动作**：偶尔歪头、左右张望，不重复机械

### 3.2 情绪状态机（P0）
| 状态 | 触发 | 表现 |
|------|------|------|
| idle 平静 | 默认 | 缓慢呼吸 + 眨眼 |
| happy 开心 | 点击它、完成任务 | 弯月眼 + 弹跳 |
| curious 好奇 | 鼠标悬停 | 眼睛放大、盯着鼠标 |
| sleepy 困倦 | 5 分钟无交互 | 眼睛半闭、呼吸变慢、偶尔"点头打瞌睡" |
| thinking 思考 | 执行任务中 | 眼睛转动 + 加载点 |
| surprised 惊讶 | 双击 | 眼睛瞪圆 |

### 3.3 快捷面板（P0）
点击 Mio 展开液态玻璃面板：
- 🕐 当前时间 / 日期 / 农历占位
- 🍅 番茄钟（25/5 分钟循环，到时通知 + Mio 提醒表情）
- ⏰ 快捷提醒（到时系统通知）
- 📊 系统状态（CPU / 内存占用）

### 3.4 窗口行为（P0）
- 无边框、全透明背景、始终置顶、不出现在 Dock
- 按住身体拖拽移动，位置记忆
- 右键菜单：置顶开关 / 透明度 / 退出
- 全局快捷键 `⌥+Space` 召唤/隐藏

### 3.5 通知提醒（P1）
- 番茄钟、提醒到时：macOS 系统通知 + Mio 跳转到屏幕中央附近弹跳提醒

## 4. 非功能需求
- 待机 CPU < 1%，内存 < 150MB
- 动画 60fps，全部用 CSS transform/opacity（GPU 合成）
- 单窗口架构，启动 < 2s

## 5. 技术选型

| 项 | 选择 | 理由 |
|----|------|------|
| 框架 | **Electron** | 跨平台、透明无边框窗口成熟、前端技术栈直接复用 |
| 机器人形象 | **纯 CSS/SVG 手绘** | 无素材依赖、矢量缩放、表情通过 class 切换状态机驱动 |
| 视觉风格 | **iOS 液态玻璃（Liquid Glass）** | 深色玻璃拟态 + 高光 + 内阴影，高级感 |
| 状态管理 | 原生 JS 状态机 | MVP 无需框架 |

## 6. 范围外（Future）
- 语音交互（接入 ASR/LLM）
- 桌宠漫游、多机器人
- 与日历/提醒事项同步
