# Mio · UI 设计规范 v1.0

## 1. 形象设定

**Mio 是一颗悬浮的深色玻璃球体**，直径 120px，无身体无底座——比 NOMI 更极简，纯靠"脸"传情。

- 球体：深空灰玻璃 `#26282F`，内含顶部高光带（模拟玻璃反射）+ 内阴影
- 边缘光：1.5px 冰蓝描边 `#85B7EB`，待机时缓慢脉动（呼吸灯）
- 眼睛：两只冰蓝发光体 `#B5D4F4`，瞳孔为深蓝 `#0C447C`，可独立位移实现视线跟随
- 嘴：仅在开心/惊讶时出现，弧线或圆点

## 2. 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 玻璃体 | `#26282F` | 球体、面板卡片 |
| 底色 | `#17181C` | 面板背景（半透明 + 毛玻璃） |
| 眼光 | `#B5D4F4` | 眼睛、主文字强调 |
| 轮廓光 | `#85B7EB` | 描边、呼吸灯 |
| 瞳孔 | `#0C447C` | 瞳孔 |
| 提醒绿 | `#1D9E75` | 番茄钟运行中状态 |
| 文字主 | `#EDEDF0` / 次 `#888A92` | 面板文字 |

## 3. 表情状态机

六种状态，CSS class 切换（`.mio--idle/.mio--happy/...`），过渡 300ms：

| 状态 | 眼睛形态 | 附加动作 |
|------|---------|---------|
| idle | 标准竖椭圆 18×24 | 呼吸缩放 4s 周期，随机眨眼 |
| happy | 弯月（上弧） | 向上弹跳 2 次，嘴出现 |
| curious | 放大 10×14 圆角 | 头部微前倾（scale 1.06） |
| sleepy | 3px 横线 | 呼吸放慢至 7s，周期性"点头" |
| surprised | 正圆 11×11 | 瞬间 scale 1.15 回弹 |
| thinking | 三点横排 | 三点波浪跳动 |

## 4. 交互规范

- **单击球体**：happy 表情 + 展开/收起快捷面板
- **双击**：surprised
- **悬停**：curious，瞳孔紧盯光标
- **长按拖拽**：移动窗口（拖拽时眼睛看向移动方向）
- **右键**：系统菜单（置顶 / 透明度 100·80·60 / 退出）
- **⌥+Space**：全局召唤/隐藏
- **5 分钟无交互** → sleepy；任何交互唤醒

## 5. 快捷面板

位于球体正上方，240px 宽，毛玻璃深色卡片，展开时带 12px 上移动画：

1. **时间卡**：大号时间 + 日期星期（秒级刷新）
2. **番茄钟**：25:00 工作 / 5:00 休息循环，运行中面板和轮廓光变绿
3. **系统状态**：CPU（loadavg 换算）+ 内存占用，5s 刷新
4. **快捷提醒**：10/30/60 分钟一键提醒，到时 macOS 通知 + Mio 弹跳

## 6. 动效原则

- 只用 `transform` / `opacity`，全部走 GPU 合成
- 生命感动画永不停（呼吸 + 眨眼是底线）
- 所有状态切换 300ms ease-out，不许跳变
