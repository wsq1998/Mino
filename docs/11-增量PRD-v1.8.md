## 1. 产品目标（一句话）

**让 Mio 第一次「开口说话」**：用户配置一个 OpenAI 兼容的云端大模型后，Mio 能以自己的人格与用户单轮问答；同时补齐分发前的两个前提（首次启动引导、自动更新提示），并把已膨胀到 2871 行的 main.js 拆成可维护的分域模块。

> 判定标准：一个全新用户拿到 DMG → 双击安装 → 首启引导 3 步走完 → 在设置 G 组填好一家服务商 → 点球体就能和 Mio 对话，全程**不出现一个英文设置项、不弹任何权限惊吓**。

### 2.2 明确不做（非目标）

- ❌ **多轮对话 / Agent / 工具调用** —— v1 只做单轮问答（路线图 §5.3 已定）。上下文管理、`mio-messages.json` 200 条上限、成本控制都要求先把「能聊、聊得像 Mio」做好
- ❌ **Ollama 专门适配** —— 只作为「自定义 Base URL」的副产物被支持（路线图 §9.1 已定），不做模型发现、不做 `/api/tags` 探测
- ❌ **electron-updater / 自动安装 / 自动重启** —— 违反零依赖约束（§9.2-E 已定），v1 只比对版本号 + 弹提示，跳转下载页
- ❌ **LLM 记忆 / 长期人格固化** —— 人格仅由 system prompt 承担，不落盘对话历史（本版不新增 `mio-llm-history.json`）
- ❌ **权限中心 I 组** —— 批次 3 已交付（检测 + 深链），本批不再新增权限类型；首启引导只做「说明 + 按需触发」
- ❌ **Developer ID 签名 + 公证** —— 批次 3 用户侧阻塞项（需 Apple 账号），本批不重复；但首启引导（B4-2）依赖「已签名」才能对别人分发，见 §8 Q1

| LLM-9 | 单轮问答（聊天面板） | P0 | 用户输入 → 回车/发送 → 请求发出（表情切 `thinking`）→ 返回后按情绪切 `happy`/`curious` → 展示回复；**每次请求只发「system + 本次用户消息」**，不携带历史 | 不做多轮上下文；返回失败 → 表情回 `idle` + 面板内一行可读错误（`❌ 401 / ❌ 超时 / ❌ 网络`），不崩溃、不静默 |
| LLM-10 | 成本控制 | P0 | 仅用户**主动发问**时调用（无后台/定时/自动触发）；每次请求带 `max_tokens`；回复后界面显示「本次估算 ≈ N tokens」；面板顶部显示「余额（估算）¥X」 | 不发任何「自动打招呼/自动续聊」；估算公式见 §5.3；**不记录对话历史**（本版无历史文件） |
| LLM-11 | 缺失配置引导 | P1 | 启用 AI 但未填 Key/Base URL/模型 → 发起对话时**不发出请求**，提示「先去设置 G 组完成配置」+ 深链到设置 G 组 | 不弹系统窗；面板内提示 |

## 5. 交互与界面设计（纯文字）

### 5.1 LLM 聊天面板形态

- **入口**：球体点击展开面板 → 常用 tab 新增卡片「和 Mio 聊聊」（仅 `settings.ai.enabled` 时出现；未启用 → 不渲染该卡片）。
- **面板形态**：点击卡片钻入 `#detailView` 详情页（复用 v1.2 钻入式详情页）：
  - 顶部：`Mio 人格名` + `余额（估算）¥X` + 「配置」小齿轮（跳 G 组）
  - 中部：**对话区**（单轮）：用户消息右对齐气泡、Mio 回复左对齐气泡；未发问时显示一句引导文案（如「想聊点什么？问我今天干嘛、或让我讲个冷笑话」）
  - 底部：输入框（单行）+ 发送按钮；**Enter 发送**（Shift+Enter 换行——本版单行可不支持换行）
  - 每次回复气泡下方：`本次估算 ~NNN tokens`
- **表情联动**（复用现有情绪状态机）：
  - 请求发出 → 切 `thinking`（已有状态）
  - 回复返回 → 按情绪切 `happy` / `curious`（默认 `happy`；回答含「？」或用户语气中性 → `curious`）
  - 失败 → 回 `idle` + 面板内一行可读错误
- **失败态文案**（面板内，不弹系统窗）：

| 场景 | 文案 |
|---|---|
| 401 | 「服务商说 Key 不对（401）。去 G 组检查一下 →」 |
| 超时 | 「等太久没回（超时）。要不换个模型或再试一次？」 |
| 网络 | 「网络好像断了。稍后再试」 |
| 未配置 | 「还没配置 AI。先去设置 → AI 助手填一下 →」（带深链） |

### 5.2 首次启动引导流程

- **形态**：独立全屏引导（面板内，非系统窗），三步横向分页 + 底部「上一步/下一步」+ 右上角「跳过」。
- **步骤**：
  1. **选城市**：`自动（IP 定位）` 单选 + 手动输入框；预览「今天 24°C · 晴」（复用天气卡渲染，失败则隐藏预览）
  2. **AI 助手**：两个大按钮「先不，谢谢（推荐）/ 启用 AI 对话」；选择「启用」→ 引导结束时自动打开 G 组
  3. **权限说明**：三行卡片（屏幕录制 / 辅助功能 / 自动化），各含「用途一句话 + 不给会怎样 + 去系统设置」；底部「开始使用」
- **完成**：写 `state.onboarding`（版本号）→ 进入主面板；**不自动触发任何 TCC 弹窗**。

### 5.3 关键参数与默认值

| 项 | 默认/取值 | 说明 |
|---|---|---|
| 服务商预设 | DeepSeek / 智谱 / 通义 / OpenAI / 自定义 | 预设表（Base URL / 模型名）硬编码在 `main` 侧 `llm/presets`，**不落盘明文 Key** |
| 默认 Base URL | 由预设决定；自定义时手填 | 兼容 OpenAI 格式 `/v1/chat/completions` |
| 默认模型 | 由预设决定 | 可改 |
| max_tokens | 512（滑块 64–2048） | 成本护栏 |
| 每月花费上限 | 关（0 = 不限制） | 估算护栏，见 LLM-7 |
| 人格（system prompt） | 预填默认 Mio 人设 | 见下方示例 |
| 检查更新 | 启动时 + 手动；两次间隔 ≥ 24h | 防 GitHub API 限流 |

**默认人设（预填 G9）**：

```
你是 Mio，一个住在用户 macOS 桌面上的小机器人伙伴。
你说话简短、亲切、偶尔俏皮；你了解用户电脑的实时状态（CPU、内存、磁盘、天气）。
你不知道的问题就老实说不知道，不编造。回答控制在 3-5 句以内。
```

**token 估算公式**（展示用，不精确）：`估算 tokens ≈ ceil(输入字符数/3) + ceil(输出字符数/3)`；花费估算 = `输入 tokens × 输入单价 + 输出 tokens × 输出单价`（单价表硬编码于 `GAP/pricing.js`，仅三家预设 + OpenAI 有价，自定义按「0 估算」显示）。

## 6. 隐私与安全设计

| 项 | 可验证断言 |

| Key 不落盘 | `userData` 下所有 JSON 文件 grep **无** `sk-` 明文；钥匙串条目 `mio-llm` 存在且值 = 用户所填 |

| 仅主动调用 | 时间轴上无任何定时/后台 LLM 调用；只有用户点「发送」才发请求 |
